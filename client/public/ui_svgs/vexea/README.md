# Vexea SVG Assets

Directory dedicated to Vexea UI, HUD, icon, and eye vector SVG files.

## Contents
- `eye_full.svg`: Full eye SVG containing both the outer contour and pupil.
- `eye_outer.svg`: Outer eye contour for standalone rendering or separate animation layer.
- `eye_pupil.svg`: Pupil SVG layer designed for dynamic aiming/look tracking animation.
